  -- confirm one order: lock it, check it, move it to C
  PROCEDURE confirm_order (p_order_id IN t_order.order_id%TYPE) IS
    l_status t_order.status%TYPE;
  BEGIN
    SELECT status INTO l_status
      FROM t_order
     WHERE order_id = p_order_id
       FOR UPDATE NOWAIT;
    IF l_status <> 'N' THEN
      raise_application_error(-20010, 'order ' || p_order_id || ' is not new');
    END IF;
    UPDATE t_order SET status = 'C', confirmed_at = SYSDATE
     WHERE order_id = p_order_id;
  END confirm_order;

  FUNCTION order_total (p_order_id IN t_order.order_id%TYPE) RETURN NUMBER IS
    l_total NUMBER(14,2);
  BEGIN
    SELECT NVL(SUM(l.qty * l.unit_price), 0) INTO l_total
      FROM t_order_line l
     WHERE l.order_id = p_order_id;
    RETURN l_total;
  END order_total;
END pkg_order;

Autopilot

One approval for a whole session.Duyệt một lần cho cả buổi làm việc.

Twenty identical approvals teach a person to click without reading. A lease replaces them with one honest act: the developer reads a card naming the connection, the statement groups, the hours and a write budget, and approves it once. Release scripts, run like SQL*Plus would read themScript release, đọc đúng như SQL*Plus

  • One statement per ;; a PL/SQL unit ends at a line holding only /; a ; inside a literal or a comment is text.
  • SET, PROMPT, SPOOL are skipped and listed. @include, EXEC, HOST, CONNECT, ALTER SESSION are refused.
  • Mỗi câu lệnh kết thúc ở ;; PL/SQL unit kết thúc ở dòng chỉ có /; ; trong chuỗi hay comment không tính.
  • SET, PROMPT, SPOOL được bỏ qua và liệt kê. @include, EXEC, HOST, CONNECT, ALTER SESSION bị từ chối.
  • Numbered files run in natural order (01_, V3__); otherwise by what each creates.
  • The whole set is previewed and approved once, then runs in order and stops at the first broken step — with the undo list and --from N to resume.
  • File có số thứ tự chạy theo thứ tự tự nhiên (01_, V3__); nếu không thì theo loại object.
  • Preview và duyệt cả bộ một lần, chạy tuần tự, dừng ở bước hỏng đầu tiên — kèm danh sách undo và --from N để chạy tiếp.

  2. Give the agent its own account: pythia agent-user --save, exactly once. It prints three statements for the DBA and saves a <name>_agent entry as the new default; the password is new on every run, so the SQL and the file must come from the same run.
